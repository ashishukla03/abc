## 3. Operational Escalation Rules

1. **Unanimous Consensus Not Required:** If a disagreement occurs, the designated owner has the tie-breaking vote.
2. **No Last-Minute Framework Changes:** Once the build window opens, the tech stack (OD-01) is strictly frozen. No transitions between Vanilla JS and frameworks are permitted mid-event.
3. **English Fallback Invariant:** If any localized string in Kannada fails verification or introduces character rendering defects, the system must immediately and gracefully fall back to the English string.
4. **Strict Pre-Event Integrity:** Zero application code may be added to `app/` prior to official event launch. Do not assume or invent organizer permission for pre-written code.
