# Gramin PocketLab — Learning Flow Index

**Project:** Gramin PocketLab — Four-Subject STEM Missions  
**Event:** STEM for Impact 2026 (Presidency University, Bengaluru)  
**Role:** Product & Learning-Flow Specialist  
**Design Standard:** Coherent 7-step pedagogical inquiry flow across Mathematics, Biology, Chemistry, and Physics. **Zero code authored; zero unrun claims.**

## Learning Flow Deliverables Directory

1. **[SHARED_LEARNING_FLOW_SPEC.md](./SHARED_LEARNING_FLOW_SPEC.md)**
   * Complete end-to-end student journey specification across all four subjects.
   * Visual **Mermaid state diagram** mapping the full 7-step lifecycle: *Mission Map (S0) $\rightarrow$ Intro (S1) $\rightarrow$ Predict (S2) $\rightarrow$ Explore (S3) $\rightarrow$ Understand (S4) $\rightarrow$ Feedback/Retry (S5) $\rightarrow$ Exit Result (S6)*.
   * Rigorous screen-by-screen breakdown specifying purpose, exact content requirements, inputs, state read/updated, validation behavior, navigation/reset rules, errors/fallbacks, accessibility requirements, and observable acceptance criteria.
   * Safety and security verification: zero microphone prompts before Physics S3, audio autoplay unblocking via synchronous gesture, and non-blocking progressive enhancement.

2. **[SCREEN_CONTRACT_TABLE.csv](./SCREEN_CONTRACT_TABLE.csv)**
   * Tabular reference matrix defining the operational contracts for Screens S0 through S6, cross-referencing purposes, inputs, state updates, validation rules, accessibility requirements, and observable criteria.
