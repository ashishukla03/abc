# Gramin PocketLab — Repository Intelligence Index

**Project:** Gramin PocketLab — Four-Subject STEM Missions  
**Event:** STEM for Impact 2026 (Presidency University, Bengaluru)  
**Role:** Repository Intelligence Lead & Open-Source Compliance Officer  
**Scope:** Open-source educational repository audit, licensing risk analysis, and reuse evaluation.  

---

## Repository Intelligence Deliverables Directory

1. **[REPO_INTELLIGENCE_REPORT.md](./REPO_INTELLIGENCE_REPORT.md)**
   * In-depth evaluations of major educational open-source projects: Kolibri, Oppia, PhET Interactive Simulations, Phyphox, Sunbird-Ed (DIKSHA), H5P, Mathigon Euclid.js, and Dexie.js.
   * Assessment of setup friction, architectural weight, offline viability, accessibility, and hackathon integration cost.

2. **[RANKED_REPOSITORY_REGISTER.csv](./RANKED_REPOSITORY_REGISTER.csv)**
   * Ranked tabular register evaluating 12 key open-source candidates with canonical repository URLs, verified SPDX licenses, asset/content terms, maintenance evidence, dependency concerns, local run verification status, and actionable recommendations.

3. **[DEPENDENCY_AND_LICENCE_RISK_NOTES.md](./DEPENDENCY_AND_LICENCE_RISK_NOTES.md)**
   * Deep-dive legal and technical risk analysis focusing on PhET Scenery build bloat and GPL-3.0 constraints, Phyphox registered trademark protections and NDK dependencies, Kolibri server bloat, and our zero-risk permissive W3C standard stack.

4. **[WHAT_TO_BORROW_VS_AVOID.md](./WHAT_TO_BORROW_VS_AVOID.md)**
   * Concise strategic guide clearly distinguishing design patterns to borrow (Kolibri offline sync queues, Oppia misconception branching, PhET visual modeling, Phyphox sensor workflows) versus pitfalls to strictly avoid (monolithic backends, GPL-3.0 code, native APK builds, heavy 3D WebGL).
